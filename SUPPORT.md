# Getting help with vibey

Please do **not** open a bug issue for a usage question. Use the channel
that matches what you need:

| I want to... | Go here |
|---|---|
| Install, configure, or conduct a delivery | [Documentation](docs/) — start with the [greeter live-demo runbook](docs/guides/greeter-live-demo.md) |
| Understand why something is designed the way it is | [Decision records](docs/architecture/decisions/) |
| Ask a question or discuss design | [GitHub Discussions](https://github.com/adammatthewsteinberger/vibey/discussions) |
| Report a bug | [Bug report](https://github.com/adammatthewsteinberger/vibey/issues/new?template=bug_report.yml) |
| Propose a feature | [Feature request](https://github.com/adammatthewsteinberger/vibey/issues/new?template=feature_request.yml) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) — privately, never as a public issue |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

This project is **macOS and Linux only**. Windows is not a supported target.
Running vibey needs PostgreSQL and at least one `*loop` engine on PATH —
`vibey doctor` reports what's missing.

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
