# Getting help with codexloop

Please do **not** open a bug issue for a usage question. Use the channel
that matches what you need:

| I want to... | Go here |
|---|---|
| Install, configure, or run an unattended session | [Documentation](https://adammatthewsteinberger.github.io/codexloop/) |
| Ask a question or discuss design | [GitHub Discussions](https://github.com/adammatthewsteinberger/codexloop/discussions) |
| Report a bug | [Bug report](https://github.com/adammatthewsteinberger/codexloop/issues/new?template=bug_report.yml) |
| Propose a feature | [Feature request](https://github.com/adammatthewsteinberger/codexloop/issues/new?template=feature_request.yml) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) — privately, never as a public issue |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

This project is **macOS and Linux only**. Windows is not a supported target;
see the [getting-started guide](https://adammatthewsteinberger.github.io/codexloop/getting-started/).

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
