# Installation

Requires **Python 3.12+** on **macOS or Linux**, and a Cursor account with
`CURSOR_API_KEY` for live runs.

```bash
pipx install cursorloop
# or
pip install cursorloop
```

From a clone:

```bash
git clone https://github.com/adammatthewsteinberger/cursorloop.git
cd cursorloop
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```
