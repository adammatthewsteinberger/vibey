# Support

## Getting help using vibey-skills

- **Installation and usage** — see the
  [Installation](https://adammatthewsteinberger.github.io/vibey-skills/installation/) and
  [Usage](https://adammatthewsteinberger.github.io/vibey-skills/usage/) guides, or the
  generated [skills reference](https://adammatthewsteinberger.github.io/vibey-skills/reference/).
- **"Does a skill exist for X?" or "why didn't a skill trigger?"** — search the
  [skills reference](https://adammatthewsteinberger.github.io/vibey-skills/reference/) for
  matching trigger phrases, or open a
  [discussion](https://github.com/adammatthewsteinberger/vibey-skills/discussions).
- **A bug in a skill, or a skill that should exist but doesn't** — open an
  [issue](https://github.com/adammatthewsteinberger/vibey-skills/issues/new/choose) using
  the bug report or feature request template.
- **Contributing a new skill or plugin** — see
  [CONTRIBUTING.md](https://github.com/adammatthewsteinberger/vibey-skills/blob/main/CONTRIBUTING.md).

## Reporting a security issue

Do not open a public issue for a security vulnerability. See
[SECURITY.md](https://github.com/adammatthewsteinberger/vibey-skills/blob/main/SECURITY.md)
for how to report one privately.

## Scope

This file covers the `vibey-skills` marketplace itself — its plugins, skills, and
packaging. Questions about Claude Code, the Claude API, or Anthropic's models belong with
[Anthropic's own support channels](https://support.anthropic.com/), not here.
